# Lista 01 — Algoritmos

Esta pasta contém os exercícios da **Lista 01** da disciplina de Estrutura de Dados I.

Os exercícios foram desenvolvidos em **C++** e praticam conceitos básicos de lógica, vetores, strings e algoritmos.

## Exercícios

* **01 - Two Sums**
* **02 - Duplicatas**
* **03 - Inverter String**
* **04 - Mover Zeros**
* **05 - Elemento Majoritário**
* **06 - Viva a Mariana**
* **07 - Data Duvidosa**

## Como executar

O projeto utiliza **CMake** e foi desenvolvido no **CLion**.

Para executar um exercício:

1. Abra o projeto no CLion.
2. Selecione o exercício desejado na configuração de execução.
3. Clique em **Run**.

Cada exercício possui seu próprio executável, então eles podem ser executados separadamente.
