# 📚 Exercícios de Estrutura de Dados I

Este repositório foi criado para guardar os exercícios desenvolvidos durante a disciplina de **Estrutura de Dados I**, do curso de **Análise e Desenvolvimento de Sistemas** no IFTM - Campus Patrocínio.

Nesta atividade, foram trabalhados principalmente conceitos de **lógica de programação, vetores, strings e algoritmos**, utilizando a linguagem **C++**.

## 💻 Exercícios

A atividade possui 7 questões:

* **Two Sum** - encontrar dois números do vetor que, somados, resultam em um valor alvo.
* **Remover Duplicatas** - remover valores repetidos de um vetor ordenado.
* **Inverter String** - inverter os caracteres de uma palavra.
* **Mover Zeros** - mover os zeros de um vetor para o final sem alterar a ordem dos outros elementos.
* **Elemento Majoritário** - encontrar o número que aparece mais de `N/2` vezes no vetor.
* **Viva a Mariana** - calcular a quantidade de números que aparecem na música até uma determinada estrofe.
* **Datas Duvidosas** - verificar se uma data pode ser interpretada de duas formas diferentes.

## 🛠️ Tecnologias

Os exercícios foram desenvolvidos utilizando:

* C++
* CLion
* CMake

## 🚀 Como executar

### Pelo CLion

1. Clone este repositório ou faça o download do projeto.
2. Abra o projeto no **CLion**.
3. Aguarde o CLion carregar o arquivo `CMakeLists.txt`.
4. Selecione o exercício que deseja executar.
5. Clique em **Run**.

Cada exercício possui seu próprio arquivo e pode ser executado separadamente.

### Pelo terminal

Também é possível compilar o projeto utilizando o CMake.

Na pasta do projeto, execute:

```bash
cmake -S . -B build
```

Depois:

```bash
cmake --build build
```

Após a compilação, basta executar o programa correspondente ao exercício desejado.

No Windows, por exemplo:

```bash
.\build\TwoSums.exe
```

## 📌 Sobre o projeto

A ideia desta atividade foi colocar em prática os conteúdos estudados nas aulas e desenvolver melhor o raciocínio para resolução de problemas utilizando algoritmos.

Os exercícios foram feitos individualmente e organizados neste repositório para facilitar tanto a execução quanto a visualização das soluções.
